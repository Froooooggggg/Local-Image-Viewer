# 简易图集查看器 · Local Image Viewer

一个 Android 上的**本地只读**图集阅读器：直接打开 zip 压缩包或文件夹里的漫画／图集，
不联网、不上传、不申请存储权限，也不需要任何服务器。

## 这个软件不会做什么

这几条是硬约束，写在代码与测试里，不是宣传语：

- **不删除、不移动、不改名你的任何原有文件**，也不申请存储权限（清单里只有 `INTERNET`）。
- 唯一的删除行为发生在你主动点「重译指定页」时：只删掉**本软件自己生成的**译文图片
  （译文目录下的 `page-NNNN.jpg`），并且只删你选中的那一段；原始压缩包与原始图片永远只读。
- 「从列表移除」只删应用内的索引与封面缓存，磁盘上的 zip／文件夹原封不动。
- 「更新」图集**只增不删**：发现新图片就并入，暂时读不到的保留。
- 除你自行配置的翻译服务外，不发起任何网络请求。

## 功能

**导入**
- zip 压缩包（单个）、单个文件夹（只读一层）、批量导入文件夹（每个 zip / 子文件夹各成一本）
- 一律通过系统文件选择器（SAF）取得授权；加密压缩包不支持

**列表**
- 搜索名称与标签；封面缩略图；每页 100 个可调；观看进度条
- 三点菜单：更新 / 重命名 / 标签 / 加入收藏夹 / 图片排序 / 信息来源 / 移除
- 长按进入多选，批量更新、打标签、加入收藏夹、排序、换位、移除

**模糊搜索**（设置里开启，默认关闭）
- 词级模糊：以词为单位比较，词序无关、允许词内拼错；中文按一字一词切分
- 子序列匹配（参照 fzf 的打分常量）：快，但要求字符顺序一致
- 临时在搜索栏用 `**` 开头也可启用

**正则搜索**（设置里开启）支持简化写法，可与普通文字混写：

| 写法 | 等价写法 | 含义 |
|---|---|---|
| `[num]` | `[数字]` | 标题内含数字 |
| `[en]` | `[英文]` | 标题内含英文字母 |
| `[ch]` | `[中文]` | 标题内含汉字（含假名、韩文） |
| `[mark]` | `[符号]` | 标题内含标点符号 |
| `[?]` | `[？]` | 任意内容，可以什么都没有 |

关键词是「含有」过滤器而非位置约束；`^` / `$` 才是首尾约束。关键词与文字之间自动补
「任意内容」，所以 `[num]Pixiv` 与 `[num] Pixiv` 等价。

**阅读器**
- 左右翻页（跟手，超过 15px 才触发）与上下滚动两种模式
- 双指缩放、单指拖动、双击缩放、音量键翻页、亮度调节
- 预加载与卸载距离可调、GIF 播放（默认暂停）、进度记忆（退出时写一次）

**翻译（可选）**
- 把当前页或整本发给你自己配置的翻译服务（同一台手机的本地服务，或局域网里的电脑）
- 译文就地叠显在原图集上，`看译文 / 看原图` 一键切换
- 支持断点续跑、单页重试、「重译指定页」、动图原样复制
- 译文目录会写入 `.nomedia`，不会出现在系统相册里

## 隐私

- 不收集任何数据，没有统计、没有崩溃上报、没有账号。
- 配对码只保存在本机（SharedPreferences），不写日志、不显示完整值。
- 翻译只会连接你填的那个地址：图片发过去、译文传回来，除此之外没有出站流量。
- 如果你把翻译服务配成云端 API，图片会上传到该服务的运营方——那是你自己的选择与风险。

## 自己构建

需要 Flutter 3.27+ 与 Android SDK（compileSdk 36）。

```bash
flutter pub get
flutter analyze          # 静态检查，应为 No issues found!
flutter test             # 单元测试
flutter build apk --release
```

产物在 `build/app/outputs/flutter-apk/app-release.apk`。

安装到真机：

```bash
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

发布版用调试证书签名（`android/app/build.gradle.kts`），换一台电脑构建出来的签名不同，
直接覆盖安装会报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`——先卸载或先备份应用数据。

### 几个值得说明的设计

**自己解析 zip**：`archive` 包的高层 API 会把每个条目的压缩数据整段读进内存，
一个 500 MB 的图集包打开一次就能吃掉整个包大小的内存。这里只读中央目录（纯元数据），
按需解压单张图片，并支持 Zip64 与大条目分块读。

**所有读取都走 SAF**：应用不申请存储权限，因此拿不到 `/sdcard/...` 的路径权限。
`content://` URI 由原生侧用 `ContentResolver` 读，Dart 侧只看到任意长度的字节流。

**不依赖文件长度**：SAF 的 `size` 经常返回 0 或不准，所有读取路径都按「读到空块为止」
的分块逻辑实现，`length()` 只作提示。

## 已知限制

- 加密压缩包不支持。
- 压缩包图集不支持「更新」：包内容不会自己变。
- 导入耗时与图片总量相关（需枚举目录并写索引）。
- 翻译质量取决于你配的翻译服务；机翻会误译、漏译，竖排文字按横排处理。
- 译文渲染由服务端完成；服务端没返回成品图时，该页会标记失败而不是伪造一张。
- 解码大图、播放动图、连续批量翻译会让 CPU / GPU 持续高负载，**设备可能发热、
  耗电加快、被系统降频**；超大图集也可能闪退。作者为个人开发，不保证绝对稳定。
